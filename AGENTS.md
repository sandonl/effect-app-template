## Web framework

Prefer TanStack Start for web applications. The template includes Start with
file-based TanStack Router routes in `apps/web/src/routes`. Keep Effect Atom for
API request state and the shared Effect HTTP API contract. SPA mode is the
default; enable server rendering only when the application needs it.
